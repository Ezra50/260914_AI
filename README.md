## ✨ Features
- 🕒 **Precision Master Clock**: Live 25fps clock with milliseconds progress indicator, 12H/24H formats, Day-of-Year, and ISO week.
- 🌐 **Global Timezones**: Live synchronized clocks for Taipei, Tokyo, Silicon Valley, New York, London, and UTC.
- ⏱️ **Productivity Suite**: Integrated Pomodoro focus timer with presets & lap stopwatch.
- 🎨 **Dynamic Themes**: 5 themes (Deep Cosmos, Cyberpunk Neon, Aurora Borealis, Emerald Matrix, Frosted Glass).
- 🌌 **Interactive Ambient Canvas**: Smooth particle network background.
- 📋 **Developer Tools**: 1-click ISO timestamp & UNIX epoch copier with audio chimes.
